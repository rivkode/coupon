## 요약

다음은 콘서트 이벤트 쿠폰에 대한 전반적인 내용을 포함하고 있다.

사용자는 쿠폰(리소스) 발급을 요청하거나 사용할 수 있으며, 쿠폰 보유 목록을 확인할 수 있다.

사용자는 현재 진행 중인 이벤트의 목록을 확인할 수 있다.

---

## 요구사항

### 쿠폰 (coupon)

#### 기능적 요구사항

**[쿠폰 발급]**

- [ ] 사용자는 유효해야 한다 (사용자 검증)
- [ ] 이벤트와 쿠폰 타입으로 사용 가능한 쿠폰 정보를 조회한다 (쿠폰 검증)
- [ ] 쿠폰 발급 가능한 수량이 존재해야 한다 (쿠폰 수량 검증)
- [ ] 쿠폰을 사용할 이벤트가 만료일자 이전이어야 한다 (쿠폰 만료 검증)
- [ ] 사용자 ID 와 쿠폰 ID 로 쿠폰을 발급하여 저장한다

**[쿠폰 사용]**

- [ ] 사용자는 유효해야 한다 (사용자 검증)
- [ ] 쿠폰을 사용한다

**[쿠폰 발급 결과 조회]**

- [ ] 사용자는 유효해야 한다 (사용자 검증)
- [ ] 사용자는 자신의 발급 요청 결과(접수/성공/매진/실패)를 조회할 수 있다
  - 발급 요청은 즉시 "접수 완료" 만 응답 → 결과는 폴링/내정보 조회로 비동기 확인

**[쿠폰 보유 목록 조회]**

- [ ] 사용자는 유효해야 한다 (사용자 검증)
- [ ] 사용자는 자신이 발급받은 쿠폰 목록을 **전체 반환**으로 조회할 수 있다 (상태 필터 없음)
  - 정렬: `issued_at DESC`
  - 페이지네이션 없음 — 사용자당 이벤트 상한 100 (§자원 제약) 으로 응답 크기 한계가 작음

#### 비기능적 요구사항

- [ ] 쿠폰 발급 시 동시성이 보장되어야 한다
- [ ] 1 초에 1,000 건의 요청에서 데이터 유실이 없어야 한다 (1,000 명 × 10 건 / 10 초)
- [ ] 응답 시간은 2 초 이내여야 한다
