# Walkthrough — 학습 / Review 용 종합 가이드

> 본 디렉토리는 **시스템 전체를 따라가는 학습 / review 용 narrative 문서** 를 둔다.
> ADR (`decisions/`) 가 결정 자체를 기록하고 보고서 (`reports/`) 가 측정 결과를 기록한다면,
> 본 디렉토리는 **"왜 그렇게 결정했고 어떤 트레이드오프를 받아들였는가"** 의 흐름을 코드 위치와
> 함께 30분 안에 따라잡을 수 있게 한다.

## 본 디렉토리의 위치

- **`decisions/`**: 각 결정을 ADR 형식으로 기록 (Status, 결정, 거부된 대안, 트레이드오프)
- **`reports/`**: 측정 결과 (Phase B/C / Day 5 사이징)
- **`runbooks/`**: 장애 / 운영 시나리오
- **`walkthrough/`**: 위 셋을 narrative 로 연결한 학습 자료 — **새 팀원 / 평가자 / 새 세션 진입 시 첫 정독**
