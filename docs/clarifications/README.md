# 요구사항 해석 / 문의

> 답변 + 본 과제의 가정을 추적한다. 답이 오기 전까지의 가정과 답변 후 갱신 영역을 명확히
> 하여 평가자가 산출물의 전제 조건을 한눈에 파악할 수 있게 한다.

## 본 디렉토리의 위치

5일 일정의 take-home 형식에서 요구사항이 100% 명확하지 않은 영역을 **추정으로 진행하지 않고
명시적 가정으로 처리** 한 흔적. 각 산출물 (보고서 / 사이징 / README) 이 본 가정 위에서 만들어졌고,
답변이 오면 정합화한다는 흐름을 본 디렉토리에서 추적.
